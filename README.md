# D&D Rogue

Projeto de roguelike 2D top-down em pixel art, desenvolvido exclusivamente com Godot 4 e GDScript.

## Protótipo atual

O gerador procedural está sendo desenvolvido em uma branch separada. O alvo inicial é uma grade lógica fixa de 48 × 28 células, independente dos tiles gráficos.

## Requisitos de desenvolvimento

- Godot 4.x
- GDScript puro; sem extensões nativas ou etapas de compilação externas
- Desenvolvimento e teste planejados para Android

Consulte a documentação do gerador na branch de protótipo antes de integrá-lo ao jogo principal.
